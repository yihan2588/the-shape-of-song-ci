# 词之形：流派与主题的语义地图

[English](FINDINGS.md) · [中文](FINDINGS.zh.md)

语义地图能否呈现宋词在风格、意象与情感上的联系？本分析结合固定的二维可视化、原始向量比较与文本细读，探索这一问题。

词是中国传统抒情文学体裁，最初依词调填作。宋词的两大风格传统是豪放与婉约：豪放多以开阔、雄健的表达见长，婉约多以细腻、含蓄的情感见长。这是总体倾向，并非每一首作品都遵循的规则。

研究问题：将每首词的自然语言嵌入存入向量数据库，再用非线性降维绘制二维地图，两大流派的作品会自然分开吗？意象或情感相近的作品，会聚成彼此邻近的“岛屿”吗？

面向读者：希望借助语义检索探索古典诗词的人。数据：2026年10月20日采集自古文岛的240篇选集条目，按统一署名规则归于96位作者。仅完整词作正文输入Qwen3-Embedding-4B，生成2,560维嵌入，经L2归一化后存入Supabase；标题、作者及流派标签均不参与拟合。

![流派分布对照](figures/01-school-separation-zh.png)

图中可见流派倾向，但没有形成两块截然分开的区域。仅8位代表词人具有作者层面的流派标签，另有152篇作品未标注。在原始向量空间中，已标注作品的轮廓系数为0.094；接近零意味着两组相互交叠。

分离不完全，部分原因可能是流派标签概括了学界对词人主导风格的认识，而非逐首作品的风格判定：豪放派代表苏轼也写过婉约深挚的悼亡词《江城子·乙卯正月二十日夜记梦》，追念亡妻。

排除同一作者的候选作品后，每篇词最相近的5篇已标注作品中，有61.4%与其流派相同；将8位作者中任意2位重分为豪放派，28种分配的平均比例为57.1%，其中8种达到或超过观察值。这项小规模的作者层面检验，尚不能确立稳健的流派边界。

## 主题在哪里相聚

核心发现：相较于按词人流派划出清晰边界，这张地图更适合帮助读者发现局部主题。提出的5个区域都是有待细读验证的假设，证据强弱并不相同。

![主题区域](figures/02-thematic-islands-zh.png)

每个编号区域取距人工选定中心最近的8个t-SNE点。坐标沿用应用中的固定结果；圆环标示本次查看的作品，并非聚类边界。原始向量的余弦相似度用来检验：图上看似相邻的作品，在降维前是否也彼此接近。

| 区域 | 余弦相似度均值 | 仅不同作者 作品配对 |
| --- | --- | --- |
| 1. 边塞与怀古 | 0.710 | 0.708 |
| 2. 抒怀 | 0.621 | 0.592 |
| 3. 田园 | 0.651 | 0.648 |
| 4. 别离与追忆 | 0.671 | 0.672 |
| 5. 闺情与相思 | 0.728 | 0.707 |
| 全部240篇（两两配对均值） | 0.624 | 0.623 |

在这5个观察窗口中，边塞与怀古、闺情与相思的相似度最高；田园与别离的均值也高于全体作品的两两相似度均值。抒怀区域则不同：排除同作者配对后的相似度仅为0.592。因此，地图下方应作更宽泛的理解，不宜视为情感一致的单一岛屿。

## 走进这些主题区域

### 1. 边塞与怀古｜左下

辛弃疾《永遇乐·京口北固亭怀古》：千古江山，英雄无觅，孙仲谋处。
张孝祥《水调歌头·和庞佑父》：湖海平生豪气，关塞如今风景，剪烛看吴钩。

历史英雄、失地之痛与征战意象，将这个区域的5位作者联系起来。称为“边塞与怀古”，比把其中所有作品都归入某一流派更准确。

### 2. 抒怀｜下方

苏轼《定风波·莫听穿林打叶声》：一蓑烟雨任平生。
苏轼《江城子·乙卯正月二十日夜记梦》：十年生死两茫茫，不思量，自难忘。

旷达自持与悼亡之痛在此相邻。8篇中有5篇出自苏轼；它既不对应单一情感，也不是跨作者相似性很强的语义岛屿。

### 3. 田园｜右下

辛弃疾《西江月·夜行黄沙道中》：稻花香里说丰年，听取蛙声一片。
秦观《行香子·树绕村庄》：树绕村庄，水满陂塘。

田野、村落、农作与乡间声息，在7位作者的作品中反复出现。豪放派与婉约派词人，因共同的田园意象在此相遇。

### 4. 别离与追忆｜右侧

柳永《雨霖铃·寒蝉凄切》：执手相看泪眼，竟无语凝噎。
欧阳修《浪淘沙·把酒祝东风》：聚散苦匆匆，此恨无穷。

离别、故人不在与节序更替，将这些作品联系起来；邻近的晏殊落花词中，也有追忆与失落之感。

### 5. 闺情与相思｜右上

李清照《一剪梅·红藕香残玉簟秋》：一种相思，两处闲愁。
唐琬《钗头凤·世情薄》：欲笺心事，独语斜阑。

亲密关系中的缺席感与室内空间反复出现。8篇中有6篇出自李清照；排除同作者配对后相似度仍较高，但共享意象并不等于情感完全相同。

结论：部分主题岛屿有助于发现和阅读作品，但尚不能认定两大流派会自动分开。应用按原始向量检索近邻，可为细读提供线索。区域是在观察地图后选定的，二维距离也可能失真。下一步应请独立读者在不看地图的情况下标注主题，并在另一部选集中检验这些发现。

文本来源：古文岛《宋词三百首》。流派背景：李伟权、李时、关莹《艺术鉴赏》第2版，清华大学出版社，2018年，第37页。
